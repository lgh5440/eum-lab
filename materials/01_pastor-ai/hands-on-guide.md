# 링크명함 만들기

---

## 준비물

- 노트북 — **작업용**
- 휴대폰이나 태블릿 — **줌 보는 용**
  (한 대로 둘 다 하시면 창 바꾸다 놓칩니다. 노트북 하나뿐이면 `윈도우 키`+`←`/`→` 로 반씩 붙여놓으세요)
- **Claude Code** (`claude.com/product/claude-code` — 미리 설치·로그인)
- **Netlify 계정** (`netlify.com` — 무료. 미리 가입)
- **내 사진 1장** · **내 종이 명함 사진** (없으면 교회 주보)

> 못 따라오셔도 됩니다. **녹화해서 보내드립니다.** 막히시면 채팅에 「막혔어요」 치세요.

---

# 0 · 준비 — 폴더 하나 만들기

바탕화면에 **「내명함」** 폴더를 만들고, **셋을 넣습니다.**

```
실습용_명함.html  ·  내 사진  ·  명함 사진
```

Claude Code 를 열고, **이 폴더를 엽니다.**

> 이 폴더 하나가 끝까지 갑니다. 만드는 것도 여기, 올리는 것도 여기입니다.

---

# 1 · 만들기

```
실습용_명함.html 을 내가 올린 사진과 정보로 바꿔줘.
다른 사람 정보는 하나도 남기지 말고 전부 지워줘.
```

다 되면 **「내명함」 폴더에서 `실습용_명함.html` 을 더블클릭**합니다.
브라우저에 내 명함이 뜹니다. **이 창을 닫지 말고 켜두세요.**

---

# 2 · 고치기

말로 고칩니다. 고치고 나서 **브라우저에서 새로고침(`F5`)** 하면 바로 보입니다.

```
예배 시간 넣어줘. 주일 오전 11시.
```
```
지나온 길에 넣어줘. 청년부 사역 10년, 선교단체 간사 5년.
```
```
아래 버튼을 주보, 헌금 안내, 오시는 길로 바꿔줘.
```
```
색을 좀 더 진하게.
```
```
방금 건 되돌려줘.
```

**말로 설명하기 어려우면 화면을 캡처해서 붙여넣고 「여기 이상해」 하면 됩니다.**

> 고친다 → **새로고침** → 본다. 이것만 반복하시면 됩니다.

---

# 3 · 카톡 미리보기 ★꼭 하세요

이걸 안 하면 카톡에 주소만 덩그러니 갑니다. **미리보기가 있어야 눌러봅니다.**

**화면에 띄워드린 미리보기 그림을 캡처해서 붙여넣으세요.**
(`윈도우 키` + `Shift` + `S` → 드래그. 나눠드린 그림 파일을 그대로 끌어다 놓으셔도 됩니다.)

그리고 이렇게 말합니다.

```
카톡에서 이렇게 미리보기 보이게 해줘.
왼쪽에 내 사진, 오른쪽에 이름·교회·한 줄 소개.
명함이랑 같은 색으로.
```

AI 가 알아서 만들어 줍니다. **그림으로 보여주면 훨씬 정확합니다.**

---

# 4 · 인터넷에 올리기

1. 브라우저에서 **`app.netlify.com/drop`**
2. **「내명함」 폴더를 통째로 끌어다 놓기**
3. 주소가 나옵니다

주소 바꾸기 — `Site configuration` → `Change site name`

---

# 5 · 카톡으로 보내기

주소를 카톡에 붙여넣으면 **사진과 이름이 그림으로 뜹니다.**

- 카톡 프로필 · 성도님께 보내는 문자 · 주보 QR · 인스타 소개란

---

## 나중에 고칠 때

```
Claude Code 에서 고치기 → 새로고침으로 확인 → 폴더를 Netlify 에 다시 끌어다 놓기
```

같은 주소로 갱신됩니다.

---

## 막힐 때

| | |
|---|---|
| 고쳤는데 화면이 그대로예요 | **새로고침(`F5`)** 하세요. 그래도 안 되면 `Ctrl`+`F5` |
| 카톡에 그림이 안 떠요 | 주소 끝에 `?1` 붙여서 다시 보내기 |
| 미리보기가 안 만들어져요 | 만들어진 그림을 캡처해서 다시 붙여넣고 `이걸 미리보기로 써줘` |
| 사진이 안 보여요 | 사진 파일이 **「내명함」 폴더 안에** 있는지 보세요 |
| 코드가 끊겼어요 | `이어서 줘` |
| 글꼴이 이상해요 | 인터넷 연결 확인 |

# 이 방법으로 할 수 있는 것

오늘 배운 건 명함 만드는 법이 아닙니다.
**남이 만든 것을 내 것으로 바꾸는 법**입니다.

처음부터 짜지 않습니다. 코딩을 배우지도 않습니다.
**이미 만들어진 것을 받아서 바꿉니다.** 그게 제일 빠릅니다.

웹페이지든, 프로그램이든, 앱이든 **방법은 하나**입니다.

```
1  받는다              연구소 자료 · 다른 목사님이 나눈 것
2  폴더에 넣고 Claude Code 로 연다
3  "내 걸로 바꿔줘. 다른 사람 정보는 전부 지우고."
4  새로고침하며 보고, 말하고, 고친다
5  올린다
```

교회 홈페이지도, 주보 앱도, 성경공부 자료도 같습니다.
**받아서 → 바꿔서 → 우리 교회에 맞게.**

그리고 목사님이 바꾼 것도, 다음 분이 또 가져다 씁니다.
연구소가 그렇게 나누고 있고, 오늘 이 명함도 그렇게 온 것입니다.

**받은 대로, 다시 나누시면 됩니다.**
