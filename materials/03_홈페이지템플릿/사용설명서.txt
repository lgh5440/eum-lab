              교회 홈페이지 사용설명서
════════════════════════════════════════════════════════════════

이 폴더가 교회 홈페이지 전체입니다.
전문 지식이 없어도 아래 순서만 따라 하시면 됩니다.


────────────────────────────────────────────────────────────────
 1. 홈페이지 미리 보기
────────────────────────────────────────────────────────────────

  index.html  파일을 마우스로 두 번 클릭하세요.
  인터넷 창이 열리면서 홈페이지가 그대로 보입니다.

  ※ 인터넷 연결 없이도 볼 수 있습니다.
    (글씨 모양만 인터넷 연결 시 더 예쁘게 나옵니다)


────────────────────────────────────────────────────────────────
 2. 내용 고치기  ★ 가장 중요 ★
────────────────────────────────────────────────────────────────

  고칠 파일은 딱 하나입니다.

      assets 폴더  →  js 폴더  →  site-data.js

  이 파일 위에서 마우스 오른쪽 클릭
   → [연결 프로그램] → [메모장] 을 고르면 열립니다.

  ┌───────────────────────────────────────────────────┐
  │  파일 안에 이런 것들이 순서대로 들어 있습니다      │
  │                                                   │
  │   1. 교회 기본 정보 (이름, 주소, 전화번호)        │
  │   2. 예배 시간표                                  │
  │   3. 공지사항                                     │
  │   4. 설교 영상 (유튜브)                           │
  │   5. 사진 갤러리                                  │
  │   6. 오시는 길                                    │
  │   7. 교회 소개 글                                 │
  │   8. 처음 오시는 분께                             │
  └───────────────────────────────────────────────────┘

  【 반드시 지켜야 할 3가지 】

   ① 작은따옴표 ' ' 안의 글자만 바꾸세요. 따옴표는 지우지 마세요.

        (○) 이름: '은혜로교회'   →   이름: '평안교회'
        (×) 이름: 평안교회                  ← 따옴표가 없음

   ② 줄 끝의 쉼표( , )는 그대로 두세요.

   ③ 다 고쳤으면 [파일] → [저장] (또는 Ctrl + S)
      그 다음 홈페이지 창에서 Ctrl + F5 를 누르면 반영됩니다.

  ※ 고치기 전에 site-data.js 파일을 복사해서 백업해 두세요.
    (파일 우클릭 → 복사 → 붙여넣기)
    잘못 고쳤을 때 백업본으로 되돌리면 됩니다.


────────────────────────────────────────────────────────────────
 3. 새 공지사항 올리기
────────────────────────────────────────────────────────────────

  site-data.js 를 열고 「3. 공지사항」 부분으로 내려갑니다.
  아래 덩어리를 통째로 복사해서, 목록 맨 위에 붙여넣고 내용만 바꾸세요.

      {
        날짜: '2026-09-01',
        분류: '공지',
        제목: '여기에 제목을 쓰세요',
        중요: false,
        내용: '여기에 내용을 쓰세요.',
      },

   · 날짜는 반드시 2026-09-01 형식(숫자4-숫자2-숫자2)
   · 중요: true  로 하면 빨간 '중요' 표시가 붙고 맨 위로 올라갑니다
   · 내용 안에서 줄을 바꾸려면  \n  을 넣으세요


────────────────────────────────────────────────────────────────
 4. 설교 영상 올리기 (유튜브)
────────────────────────────────────────────────────────────────

  ① 설교 영상을 유튜브에 먼저 올립니다.
  ② 그 영상의 주소를 봅니다.

        https://www.youtube.com/watch?v=AbCdEfGh123
                                       ~~~~~~~~~~~
                                       이 부분만 복사

  ③ site-data.js 「4. 설교 영상」의 유튜브ID 칸에 붙여넣습니다.

        유튜브ID: 'AbCdEfGh123',

  ※ 주소가 https://youtu.be/AbCdEfGh123 형태면
    마지막 / 뒤의 글자를 넣으시면 됩니다.


────────────────────────────────────────────────────────────────
 5. 사진 올리기
────────────────────────────────────────────────────────────────

  ① 사진 파일을  assets 폴더 → img 폴더  안에 넣습니다.
     파일 이름은 반드시 영어와 숫자로! (예: summer2026.jpg)
     한글 파일명은 인터넷에서 사진이 안 보일 수 있습니다.

  ② site-data.js 「5. 사진 갤러리」에서 파일 칸을 채웁니다.

        { 제목: '여름수련회', 날짜: '2026-07', 파일: 'assets/img/summer2026.jpg' },

  ※ 사진이 너무 크면(5MB 이상) 홈페이지가 느려집니다.
    스마트폰 사진은 '카카오톡으로 나에게 보내기' 후 다시 받으면
    자동으로 작아져서 쓰기 좋습니다.


────────────────────────────────────────────────────────────────
 5-2. 홈 화면 큰 그림 바꾸기
────────────────────────────────────────────────────────────────

  지금은 밝은 낮 교회 풍경을 모자이크로 표현한 그림이 들어가 있습니다.
  site-data.js 「1. 교회 기본 정보」 안에 이 두 줄이 있습니다.

      메인사진:    'assets/img/hero-mosaic.svg',
      환영문구:    '은혜로교회에 오신 것을 환영합니다',

  ▸ 큰 글씨를 바꾸려면
      환영문구 의 따옴표 안 글자를 바꾸세요.

  ▸ 이미 들어 있는 그림 2가지 중에 고르려면
      'assets/img/hero-mosaic.svg'  … 밝고 부드러운 낮 교회 · 모자이크
      'assets/img/hero.svg'         … 해질녘 불 켜진 작은 개척교회 (어두운 느낌)

  ▸ 실제 교회 사진으로 바꾸려면
      1) 사진을 assets/img 폴더에 넣습니다 (파일명은 영어! 예: church.jpg)
      2) 메인사진 칸을 'assets/img/church.jpg' 로 바꿉니다

      ※ 가로로 넓은 사진이 가장 잘 어울립니다 (가로 1600 × 세로 620 정도).
      ※ 글씨 카드가 왼쪽에 올라가므로,
        교회 건물이 사진의 오른쪽에 있는 사진이 가장 예쁩니다.

  ▸ 그림을 아예 없애려면
      메인사진: '',   ← 이렇게 비우면 짙은 남색 배경만 나옵니다


────────────────────────────────────────────────────────────────
 6. 지도 넣기
────────────────────────────────────────────────────────────────

  지금은 주소와 '카카오맵 길찾기 / 네이버지도 길찾기' 버튼이
  자동으로 나옵니다. 이대로 두셔도 충분합니다.

  지도 그림을 직접 넣고 싶으시면:

  ① google.com/maps 에서 교회 주소를 검색
  ② [공유] → [지도 퍼가기] → [HTML 복사]
  ③ 복사된 글자 중  src="여기주소"  의 따옴표 안 주소만 골라
  ④ site-data.js 「6. 오시는 길」의 지도주소 칸에 붙여넣기


────────────────────────────────────────────────────────────────
 7. 인터넷에 무료로 공개하기  (약 5분, 비용 0원)
────────────────────────────────────────────────────────────────

  ① 인터넷에서  netlify.com  에 접속합니다.
  ② [Sign up] 을 눌러 구글 계정으로 가입합니다. (무료)
  ③ 로그인 후 나오는 화면에서
        [Add new site] → [Deploy manually]
     를 누릅니다.
  ④ 네모난 회색 상자가 나옵니다.
     이 church-website 폴더를 통째로 마우스로 끌어다 놓습니다.
  ⑤ 30초쯤 기다리면 주소가 만들어집니다.
        예)  https://sparkly-cat-12345.netlify.app
  ⑥ [Site configuration] → [Change site name] 에서
     주소 앞부분을 교회 이름으로 바꿀 수 있습니다.
        예)  https://gracechurch.netlify.app

  ※ 내용을 고친 뒤에는?
    같은 화면의 [Deploys] 탭에 폴더를 다시 끌어다 놓으면
    새 내용으로 바뀝니다. (1분 이내)

  ※ www.교회이름.kr 같은 주소를 쓰고 싶으시면
    도메인을 따로 구입해야 합니다 (연 1~2만원).
    구입 후 Netlify의 [Domain management] 에서 연결합니다.

 8. 폴더 안에 무엇이 있나
────────────────────────────────────────────────────────────────

  index.html ......... 홈 화면
  about.html ......... 교회 소개
  worship.html ....... 예배 안내
  sermons.html ....... 설교 말씀
  news.html .......... 공지사항
  gallery.html ....... 사진
  location.html ...... 오시는 길

  assets/js/site-data.js ... ★ 내용 파일 (여기만 고치세요)
  assets/js/main.js ........ 화면을 그려주는 파일 (건드리지 마세요)
  assets/css/style.css ..... 색과 모양을 정하는 파일
  assets/img/ .............. 사진을 넣는 폴더


────────────────────────────────────────────────────────────────
 9. 문제가 생겼을 때
────────────────────────────────────────────────────────────────

  Q. 고쳤는데 홈페이지에 안 바뀌어요
   → 저장(Ctrl+S)을 했는지 확인하고,
     홈페이지 창에서 Ctrl + F5 를 누르세요.

  Q. 화면이 하얗게 되고 아무것도 안 나와요
   → site-data.js 에서 따옴표나 쉼표를 실수로 지운 경우입니다.
     메모장에서 Ctrl + Z 를 여러 번 눌러 되돌린 뒤 저장하세요.
     백업해 둔 파일이 있으면 그것으로 바꾸면 됩니다.

  Q. 글씨체가 좀 달라 보여요
   → 인터넷 연결이 없을 때 나타납니다. 연결되면 정상으로 나옵니다.

  Q. 사진이 안 보여요
   → 파일 이름에 한글이나 띄어쓰기가 있는지 확인하세요.
     영어와 숫자로만 된 이름으로 바꾸면 해결됩니다.
