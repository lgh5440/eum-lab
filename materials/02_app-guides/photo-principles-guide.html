이음 포토 (eum-photo)

교회학교 사진을 사용자 컴퓨터 안에서 정리하는 로컬 우선 도구입니다.

원칙

  • 사진 원본을 서버에 올리지 않습니다.
  • 현재 MVP는 브라우저 메모리에서만 사진을 분석합니다.
  • 이음 스쿨과는 CSV/JSON 명단 import 방식으로 느슨하게 연결합니다.

기능 요약

정리 흐름

  • 여러 사진 선택 또는 드래그 앤 드롭 (작업 도중에도 워크스페이스 어디든 추가 가능)
  • 날짜별 자동 그룹, 이미지 해시 기반 중복 후보, 샘플 픽셀 대비 기반 흐림 후보 탐지
  • 행사명·학생 이름 태그 (직접 입력 또는 명단 CSV 칩 클릭)
  • 대표·보관·공개후보·제외 선별 (키보드 1·2·3·4 단축키, 사진 카드에 배지로 표시)
  • 대표 인물 폴더 만들기 (확대 보기 얼굴 박스 → 이름 입력) · 이름 변경 / 삭제 도구

명단 매칭과 공개 동의

  • 학생 명단 CSV (이름·반·공개동의 컬럼) import
  • 명단 칩에 매칭 사진 수 배지 + 공개 동의 ✓/✗/? 표식
  • 공개 후보 사진에 미동의 학생이 포함되면 사진 카드에 빨간 「공개 미동의」 뱃지와 자동 검토 항목 표시
  • 정리안 JSON에 사진별 consent 블록과 rosterMatch 요약 포함

내보내기

  • 로컬 폴더 저장 (Chrome/Edge): 사용자 폴더에 행사/상태/인물 구조 + _정리안.csv + _정리안.json
  • 정리본 ZIP: 모든 브라우저 호환, 같은 폴더 구조를 ZIP으로
  • Google Drive: OAuth client_id 설정 시 활성, drive.file 권한만 사용
  • 정리표 ▾ 드롭다운: 사진 없이 CSV / JSON만

누적 통계

  • 이 행사 누적에 추가로 행사 단위 사진 분포를 localStorage에 누적
  • 학생별 누적 사진 수가 다음 행사에서도 합산되어 등장 균형을 비교

교사 친화 보강

  • 첫 화면에 4단계 작업 가이드와 「새로고침 시 사진 사라짐 → 작업 저장 권유」 빨간 안내
  • 사진이 들어와 있을 때 새로고침/창 닫기 시 OS 기본 「변경 저장 안 됨」 경고
  • 비우기 / 기록 비우기 확인 다이얼로그
  • 행사명 default 빈값 + placeholder + 비어 있을 때 사이드바 빨간 경고
  • 사진 분석 진행률 X/Y 표시
  • 모바일에서 사이드바를 ☰ 토글로 슬라이드 인 패널 처리

실행

npm install
npm run dev

작업 저장 방식

  • 작업 저장은 사진 원본이 아니라 태그, 상태, 인물 폴더, 얼굴 박스 정보를 JSON으로 저장합니다.
  • 다시 작업할 때는 원본 사진을 먼저 추가한 뒤 작업 불러오기로 JSON을 선택합니다.
  • 파일명, 파일 크기, 수정 시간을 기준으로 같은 사진을 찾아 기존 작업 상태를 복원합니다.
  • 학생 명단 CSV는 이름, 성명, 학생명, name 열을 우선 읽고, 없으면 첫 번째 열을 이름 목록으로 사용합니다.
  • Chrome/Edge에서는 로컬 폴더 저장으로 선택한 폴더 안에 행사/상태/인물별 하위 폴더와 _정리안.csv, _정리안.json을 직접 만들 수 있습니다.
  • 폴더 직접 저장을 지원하지 않는 브라우저에서는 정리본 ZIP을 사용합니다 (_정리안.csv/_정리안.json 동봉).
  • 정리안 JSON은 행사/인물 요약과 사진별 권장 폴더·파일명을 포함하므로 이음 스쿨이나 다른 도구로 import할 수 있습니다.
  • 배포 빌드에서는 PWA 기본 설정이 적용되어 데스크탑/모바일에서 설치형 웹앱처럼 사용할 수 있습니다.

Google Drive 저장 설정 (선택)

Google Drive 버튼은 OAuth client_id가 설정된 경우에만 보입니다.

  1. Google Cloud Console에서 새 프로젝트를 만들고 OAuth 동의 화면과 OAuth 2.0 Client ID(웹 애플리케이션)를 생성합니다.
  2. 승인된 JavaScript 원본에 빌드를 호스팅하는 도메인(예: http://localhost:5173)을 추가합니다.

  3. 프로젝트 루트에 .env.local 파일을 만들고 다음 값을 적습니다.

    text VITE_GOOGLE_CLIENT_ID=발급받은_클라이언트_ID

  4. npm run dev 또는 npm run build를 다시 실행합니다.

  5. 첫 사용 시 Google 로그인 창이 열려 drive.file 권한을 묻습니다(이 앱이 만든 파일만 접근).

drive.file 범위만 사용하므로 기존 Drive 파일은 건드리지 않습니다. 행사 단위로 새 폴더를 만들고 그 안에 행사/상태/인물 구조와 _정리안.csv/_정리안.json을 함께 업로드합니다.
