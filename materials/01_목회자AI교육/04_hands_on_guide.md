# 노트북 실습 가이드

## 실습 전 준비

필수:
- 노트북
- 브라우저
- AI 도구 계정
- 실습용 사역 문제 1개

선택:
- Roblox 계정
- Roblox Studio 설치
- Roblox published experience 링크

금지:
- 실제 아동 이름
- 교인 연락처
- 생년월일
- 주소
- 사진 원본
- 교회 내부 명단

## 실습 1. 사역 문제를 앱 아이디어로 바꾸기

아래 양식을 채웁니다.

```text
사역 영역:
대상:
반복되는 문제:
현재 해결 방식:
불편한 점:
첫 버전에서 꼭 필요한 기능 3개:
절대 하면 안 되는 것:
```

AI에게 붙여넣습니다.

```text
당신은 교회 사역과 초보자용 앱 기획에 익숙한 기획자입니다.
나는 코딩을 모르는 목회자입니다.
아래 내용을 바탕으로 작은 첫 버전 앱 아이디어를 정리해 주세요.

사역 영역:
대상:
반복되는 문제:
현재 해결 방식:
불편한 점:
첫 버전에서 꼭 필요한 기능 3개:
절대 하면 안 되는 것:

산출물:
1. 앱 이름 후보 3개
2. 한 줄 설명
3. 사용자 2종류
4. 화면 5개 이하
5. 첫 버전 기능 3개
6. 개인정보와 아동 안전 주의사항
```

## 실습 2A. 앱/웹 프로토타입 방향

```text
위 기획을 바탕으로 브라우저에서 열 수 있는 간단한 웹앱 프로토타입을 만들고 싶습니다.
아직 로그인, 데이터베이스, 실제 저장은 필요 없습니다.
화면 전환 느낌과 사용 흐름만 보이면 됩니다.

먼저 화면별 구성표를 만들어 주세요.
각 화면에는 제목, 설명, 버튼, 입력칸, 표시 정보를 포함해 주세요.
```

추가 개선 프롬프트:

```text
이 화면 구성을 60대 교사도 쉽게 이해할 수 있게 더 단순하게 줄여 주세요.
버튼 이름은 짧고 명확하게 바꿔 주세요.
```

## 실습 2B. Roblox/메타버스 방향

```text
위 사역 아이디어를 Roblox 또는 메타버스 교육 공간으로 바꿔 주세요.
대상은 초등부/중고등부/청년부 중에서 __________ 입니다.

다음 항목으로 표를 만들어 주세요.
1. 공간 이름
2. 아이들이 하는 행동
3. 배울 말씀 또는 메시지
4. 필요한 오브젝트
5. 교사가 확인할 점
```

추가 개선 프롬프트:

```text
이 Roblox 월드 설계를 2시간 워크숍에서 설명할 수 있는 수준으로 줄여 주세요.
처음 만드는 사람이 구현하기 쉬운 순서로 1단계, 2단계, 3단계로 나눠 주세요.
```

## 실습 2C. 운영 자동화 방향

```text
위 사역 문제를 자동화 흐름으로 정리해 주세요.
실제 개인정보를 쓰지 않는 샘플 데이터 기준으로 설명해 주세요.

표에는 입력, 처리, 출력, 사람이 확인할 지점, 위험 요소를 넣어 주세요.
```

추가 개선 프롬프트:

```text
이 자동화에서 사람이 반드시 최종 확인해야 하는 지점을 표시해 주세요.
실수하면 큰 문제가 되는 부분은 빨간불 항목으로 따로 정리해 주세요.
```

## Roblox 실습을 할 경우

강사가 사전에 준비해야 할 것:

- published experience 링크
- Roblox Studio 설치 안내
- 시연용 계정
- 테스트용 place
- 재생성/초기화 명령은 직접 실행하지 않거나, 복사본에서만 실행

참여자에게 시킬 수 있는 안전한 활동:

- 공간 구성 아이디어 만들기
- 안내판 문구 만들기
- 미션 흐름 만들기
- AI 이미지 프롬프트 만들기
- 오브젝트 목록 만들기

초보자에게 바로 시키기 위험한 활동:

- 기존 월드 전체 재생성
- publish 버튼 누르기
- 실제 아동 정보 입력
- 외부 링크 삽입
- 채팅/친구추가 설정 변경

