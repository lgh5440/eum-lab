# 안전, 윤리, 저작권 체크리스트

## 교육 중 절대 원칙

- 실제 아동 이름, 연락처, 주소, 생년월일을 AI 도구에 입력하지 않습니다.
- 교회 내부 명단이나 민감한 상담 내용을 실습 데이터로 쓰지 않습니다.
- AI가 만든 성경 해석과 신학 표현은 목회자가 최종 검수합니다.
- 외부 교재 이미지, 악보, 영상, 캐릭터를 권한 없이 그대로 복제하지 않습니다.
- Roblox나 웹앱을 공개하기 전에는 채팅, 외부 링크, 개인정보 입력 여부를 확인합니다.

## 저작권 기준

DAVID 사례의 경우:

- 성경학교 내용 사용은 PETMOSS에 전화로 확인된 상태입니다.
- 성경학교 이미지 자료는 그대로 사용하지 않습니다.
- 이미지는 AI를 활용해 새롭게 제작한 자료를 사용합니다.
- 교육 자료에는 "원본 교재 이미지를 복제하지 않고, 내용을 바탕으로 새 시각 자료를 제작했다"는 원칙을 밝힙니다.

강의 자료 제작 시 확인할 것:

- 교재 본문을 어느 범위까지 인용할 수 있는가
- PPT/PDF 화면 캡처를 외부 교육에서 보여도 되는가
- AI 이미지가 특정 작가/캐릭터 스타일을 과도하게 모방하지 않는가
- 음악, 챈트, 영상 사용 범위가 내부 시연인지 외부 배포인지

## 아동/청소년 안전

Roblox 또는 메타버스 활동 전:

- 공개 서버인지 비공개 서버인지 확인
- 채팅 기능 관리 가능 여부 확인
- 친구추가/DM/외부 링크 노출 여부 확인
- 교사 또는 스태프 감독자 지정
- 아이들이 개인 신상 정보를 말하지 않도록 사전 안내
- 화면 녹화와 사진 촬영 동의 기준 정리

웹앱 또는 폼 활동 전:

- 이름 대신 별명/번호 사용 가능 여부 확인
- 연락처 수집이 꼭 필요한지 재검토
- 저장 위치와 접근 권한 확인
- 삭제 요청이 들어오면 지울 수 있는지 확인
- 관리자 계정을 누가 관리하는지 정리

## AI 결과물 검수 질문

신학:
- 본문 의미를 왜곡하지 않았는가?
- 복음, 믿음, 순종, 은혜 등의 표현이 교회 입장과 맞는가?
- 아이들이 오해할 만한 표현은 없는가?

교육:
- 대상 연령이 이해할 수 있는가?
- 재미가 메시지를 가리지 않는가?
- 느린 학습자도 참여할 수 있는가?

운영:
- 교사가 실제로 운영할 수 있는가?
- 준비물이 과하지 않은가?
- 인터넷이 느리거나 기기가 부족할 때 대안이 있는가?

기술:
- 실제 데이터 없이 테스트했는가?
- 오류가 나면 멈출 수 있는가?
- 누가 수정했는지 기록되는가?

## 공개 전 최소 점검

- [ ] 실제 개인정보가 들어 있지 않다.
- [ ] 원본 교재 이미지를 무단 복제하지 않았다.
- [ ] AI 이미지 사용 범위를 확인했다.
- [ ] 성경 본문과 메시지를 사람이 검수했다.
- [ ] Roblox 공개 범위와 채팅 설정을 확인했다.
- [ ] 외부 링크가 불필요하게 노출되지 않는다.
- [ ] 교사/관리자 역할이 정해져 있다.
- [ ] 문제가 생기면 중단할 방법이 있다.
